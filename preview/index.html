🖥️ Installation (1 double-clic)

Installer.bat télécharge la dernière version depuis GitHub, l'installe dans ton dossier utilisateur (aucun droit admin), crée un raccourci sur le Bureau + menu Démarrer, et Lance le jeu.

🔄 Mises à jour 100 % auto

  • Le jeu vérifie GitHub à chaque démarrage : si une version plus récente existe, il la télécharge et propose Entrée pour l'appliquer (remplacement + relancement automatiques).
  • Ou relance simplement Installer.bat : il met à jour si besoin.

🌱 Sortir une nouvelle version

Change le numéro dans version.txt, pousse sur main : GitHub Actions fabrique le .exe et publie la Release tout seul. Tous les joueurs sont mis à jour au prochain lancement.
